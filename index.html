Eloquente Catering System (ECS) with Decision Support System

Authors: John Maverick M. Aquino • Rafael Angelo P. Buscano • John Darev A. Donato • Tyron Jude G. Duran
Adviser: Ms. Geliza Marie I. Alcober • Industry Partner: Eloquente Catering Services • Core Engine: Predictive DSS & PayMongo Integration

1. Operational Problem & Core Innovation

Traditional catering operations at Eloquente Catering Services suffered from disjointed manual workflows: handwritten booking slips, unverified manual bank transfer checks, phone-based pricing recalculations, and perishable grocery purchasing based on guesswork rather than empirical forecasting.

Engineered Solution: ECS provides an integrated web platform linking customer intake with automated rule-based pricing, instant PayMongo reconciliation, automated kitchen prep sheets, and predictive analytics forecasting sales and guest turnout with mathematical precision.

2. System Architecture & Quality Benchmarks (ISO/IEC 25010)

Laravel 11 Inertia.js React 18 Tailwind CSS PostgreSQL PayMongo API
  • Functional Suitability: 100% verified test cases covering dynamic rules, deposits, and kitchen prep sheets.
  • Reliability & Webhooks: Zero-drop automated payment reconciliation with immutable double-entry ledger.
  • Security & Audit Trail: Role-Based Access Control (RBAC) with immutable event logging (User ID, IP, and timestamp).

3. Sequential 4-Stage Catering Operations Lifecycle

Stage 1 Customer Intake

7-step booking engine, Smart Budget Maximizer, instant PayMongo cashless deposit, live milestone tracker.

Stage 2 Sales Triage

Event capacity thresholds, calendar blackout dates, food tasting coordination, automated kitchen prep checklists.

Stage 3 Financial Settlement

Automated webhook verification for GCash, Maya, and cards, BIR-compliant digital receipts, double-entry ledger.

Stage 4 Admin Governance

Predictive DSS revenue/demand models, holiday surcharge rule engine, tamper-proof audit trails.
